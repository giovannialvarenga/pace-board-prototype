Part 02

Pilot Playbook

Step-by-step guide for each of the 3 customer sessions. Run this in order — one session at a time.

◎
Before the Session
Outreach, pre-brief, preparation
1

Send the outreach message

From products/pace-board/assets/onboarding-pilot.md — Part 1.

Personalize the first sentence with their specific context before sending.

2

Get their one-sentence challenge as reply

Wait for their response. This is the opening message for the session. Copy it exactly.

3

Send the pre-session brief — 24 hours before

From products/pace-board/assets/onboarding-pilot.md — Part 2.

●
Running the Session
40–50 min — run this live
1

Open a new Claude Code session

Separate from this session. A clean context with no prior conversation.

2

Load the Strategist context

Tell Claude exactly:

You are the PACE Strategist. Load your system prompt from products/pace-board/agents/strategist/system-prompt.md and these methodology files:

Files to load
methodology/core/v1.0/maturity-dimensions.md
methodology/core/v1.0/module-matrix.md
methodology/core/v1.0/tracks.md
upstream/v1/rules.json
upstream/v1/templates/upstream-opinion.md
3

Paste the customer's one-sentence challenge

This is the opening message. Paste it exactly as received. Do not paraphrase.

4

Let the Strategist run the full sequence

The flow is automatic: Discovery → Upstream → [confirm focus + mode] → Batch generation.

Do not interrupt. Follow the Strategist's lead. Answer honestly on behalf of the customer if needed.

5

Copy all generated outputs

Wait for the full batch. The Strategist will generate all 5 artifacts in sequence. Copy them before closing the session.

◆
After the Session
Within 24 hours
1

Save the 5 artifacts as files

Use [customer] as the customer's first name or handle.

File naming convention
[customer]-upstream-opinion.md
[customer]-world-model.md
[customer]-worldview.md
[customer]-movement-plan.md
[customer]-trial-prompts.md
2

Send the post-session delivery

From products/pace-board/assets/onboarding-pilot.md — Part 3.

Include links to the 5 artifact files.

3

Log friction points

Open the friction log and document anything that felt slow, confusing, or wrong during the session.
